Como correr 
1. navegar até src/main/java
2. compilar com javac -d ..\..\..\target\ -cp ..\..\..\target\lib\jsoup-1.18.3.jar search\*.java ---no linux-->  javac -d ../../../target/ -cp "../../../target/lib/jsoup-1.18.3.jar" search/*.java
3. correr
4. navegar ate target
5. java -cp ".;lib/jsoup-1.18.3.jar" search.Client  -----no linux--> java -cp ".:lib/jsoup-1.18.3.jar" search.Gateway
